# Oportunidades de Granos 1.0.2

- **Aviso de nueva versión dentro de la app**: cuando se publica una versión más
  nueva, aparece un cartel *"Nueva versión X disponible"* con un botón
  **Actualizar** que abre la descarga del APK.
- En **Ajustes → Acerca de** se indica si tenés la última versión.
- La app lee `data/version.json` del repositorio para comparar con la versión
  instalada.
