# Oportunidades de Granos 1.0.1

Mejoras de claridad para que sea más fácil de usar, pensando en el usuario final.

## Cambios

- El **puntaje** se muestra como `66/100` y se explica: *cuanto más alto, mejor es
  el momento*.
- Cada tarjeta incluye una **recomendación en castellano claro** ("Buen momento
  para comprar", "Puede convenir: estate atento", "Todavía no es el mejor
  momento").
- Se reemplazó **"Sin señal"** por **"Esperar"** (evita confundirlo con la señal
  del celular).
- **Detalle más simple**: los indicadores técnicos (percentil, z-score, RSI,
  medias) quedan dentro de *"Ver detalles técnicos"*.
- Textos de ayuda en **Ajustes** y en el **onboarding** (el flete es opcional y se
  puede ajustar después).
- Arranque más rápido: las notificaciones se inicializan después de mostrar la app.
- Aviso automático si los datos tienen más de 3 días.

## Requisitos

- Android 8.0 (API 26) o superior.

## Instalación

Descargar `app-release.apk`, permitir orígenes desconocidos e instalar. Aceptar el
permiso de notificaciones (Android 13+).
