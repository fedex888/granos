# Oportunidades de Granos 1.0.0

Primera versión de la app para detectar oportunidades de compra y venta de granos.

## Qué incluye

- Precios de referencia de **maíz, soja, trigo pan y girasol** (BCR Rosario), en
  ARS/t y USD/t.
- **Score de oportunidad 0-100** y señal (comprar / vender / mirar).
- Gráfico de **2 años** con mínimo y promedio.
- Detalle con RSI, medias, z-score y **precio local estimado** (Rosario ± flete).
- **Alertas push** que abren el detalle del producto.
- Funciona **offline** con el último dato cacheado.

## Requisitos

- Android 8.0 (API 26) o superior.

## Instalación

1. Descargar `app-release.apk`.
2. Permitir la instalación de orígenes desconocidos.
3. Instalar y aceptar el permiso de notificaciones (Android 13+).

## Aviso

Esta aplicación es una herramienta de referencia y **no constituye asesoramiento
financiero, comercial ni de inversión**. Los precios pueden estar desactualizados o
contener errores. Verificá siempre con tu corredor, acopio o cooperativa antes de
operar.
